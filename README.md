# DEMI: Direct Effects Multiplicative Inference

DEMI predicts patient outcomes from pairwise relationships among clinical concepts. It does not need the full joint distribution or a complete feature vector for each patient. This repository will hold the reference implementation for the following paper.

> Alemi F, Lin Y, Elyazori HRA, Franzuela Cardenas V, Ramezani N, Lybarger K. Direct Effects Multiplicative Inference (DEMI): Causal Prediction from Pairwise Clinical Relationships, Applied to Antidepressant Response. *Journal of Biomedical Informatics*. In press.

## Status

The code is not posted yet. It will be released here when the article is published. 

The repository will contain the algorithm, documentation, and worked examples. It will not contain patient-level data or the pairwise-relationship knowledgebase.
