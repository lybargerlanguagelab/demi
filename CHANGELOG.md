# Changelog

Versions are git tags on this repository. Internal version numbers follow the lab's development history; not every internal version is released here.

## v17 (2026-10-23)

The algorithm version evaluated in Alemi et al., *Journal of Biomedical Informatics*, 2026, doi:10.1016/j.jbi.2026.105111. Contents: `demi.py` (library), `paper/demi_as_reviewed.py` (the code that accompanied the manuscript through review, unchanged), the synthetic and sertraline worked examples, license, and reproducibility notes. Both code files reproduce the article's synthetic example exactly.
